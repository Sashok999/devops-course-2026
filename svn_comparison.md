### 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В git ветка представляет из себя один файл весом 41 байт(в файле хранится еш коммита), а в svn ветвление состоит из копирования дериктории в реопзитории. 

### 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет, нельзя, т.к. svn централизован  На рабочей машине разработчика хранится только рабочая копия, а сам репозиторий хранится исключительно на центральном сервере.

### 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

Хотя индустрия массово перешла на Git, SVN сохраняет сильные позиции в специфических корпоративных сценариях:

1. Работа с гигантскими нетекстовыми ассетами (геймдев, 3D, медиа)

2. Эксклюзивная блокировка файлов (File Locking)

3. Частичный чекаут (Sparse Checkout)
